Инструкция по запуску бота:

1. Установите Python 3.10+ и pip.
2. Установите библиотеку discord.py:
   pip install -U discord.py
3. В файле config.py вставьте токен своего бота вместо "Discord TOKEN с бота".
4. Запустите бота:
   python bot.py
5. Команды в Discord:
   !kick @user причина
   !ban @user причина
   !mute @user
   !unmute @user
   !role @user НазваниеРоли
